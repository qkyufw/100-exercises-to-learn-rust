## 1. for 循环的底层原理

### 1.1 语法糖解构

每次我们写一个 `for` 循环时，Rust 编译器会将其"解语法糖"（desugar）为以下代码：

```rust
// 我们写的代码
let v = vec![1, 2, 3];
for n in v {
    println!("{}", n);
}

// 编译器实际展开的代码
let mut iter = IntoIterator::into_iter(v);
loop {
    match iter.next() {
        Some(n) => {
            println!("{}", n);
        }
        None => break,
    }
}
```

### 1.2 关键要点

- `loop` 是 Rust 中最基础的循环结构，会无限运行直到显式 `break`
- `for` 循环本质上是调用 `IntoIterator::into_iter()` 创建迭代器
- 然后循环调用 `next()` 方法，直到返回 `None`

### 1.3 性能优势

使用迭代器而非索引访问的优势：

```rust
// 更快的方式（迭代器）
let v = vec![1, 2, 3];
for n in v {
    println!("{}", n);
}

// 较慢的方式（索引访问）
let v = vec![1, 2, 3];
for i in 0..v.len() {
    println!("{}", v[i]); // 每次访问都需要边界检查
}
```

**原因**：迭代器不会越界，编译器可以移除边界检查，生成的机器代码更快。

## 2. Iterator trait

### 2.1 定义

`Iterator` trait 定义了可以产生值序列的类型的共享接口：

```rust
trait Iterator {
    type Item;  // 关联类型，指定产生的值类型
    fn next(&mut self) -> Option<Self::Item>;
}
```

### 2.2 核心方法

- `next()`: 返回序列中的下一个值
  - 有值：返回 `Some(value)`
  - 无值：返回 `None`

### 2.3 重要说明

- 返回 `None` 并不保证迭代器已耗尽（除非实现了 `FusedIterator` trait）
- `Iterator` 的所有其他方法都基于 `next()` 实现

## 3. IntoIterator trait

### 3.1 定义

`IntoIterator` trait 定义了可以转换为迭代器的类型：

```rust
trait IntoIterator {
    type Item;
    type IntoIter: Iterator<Item = Self::Item>;
    fn into_iter(self) -> Self::IntoIter;
}
```

### 3.2 关键特性

- `into_iter()` 方法**消耗** `self`，返回一个迭代器
- 一个类型只能有一个 `IntoIterator` 实现（避免 `for` 循环的歧义）
- 实现了 `Iterator` 的类型会自动实现 `IntoIterator`（直接返回自己）

### 3.3 练习 04：为 TicketStore 实现 IntoIterator

**目标**：让 `TicketStore` 可以在 `for` 循环中使用

**实现**：

```rust
// exercises/06_ticket_management/04_iterators/src/lib.rs

impl IntoIterator for TicketStore {
    type Item = Ticket;                          // 迭代器产生的元素类型
    type IntoIter = std::vec::IntoIter<Ticket>;  // 迭代器的具体类型

    fn into_iter(self) -> Self::IntoIter {
        self.tickets.into_iter()  // 委托给内部 Vec 的迭代器
    }
}
```

**使用方式**：

```rust
let store = TicketStore::new();
// ... 添加票据 ...

// 消耗所有权，获取 Ticket
for ticket in store {
    // ticket 的类型是 Ticket（拥有值）
    println!("{}", ticket.title);
}

// store 在此处已被消耗，无法再使用
```

**关键点**：
- `type IntoIter` 必须是实现 `Iterator` trait 的类型
- `Vec::into_iter()` 返回 `std::vec::IntoIter<T>`
- 我们"委托"给内部的 `Vec` 字段，而非自己实现迭代逻辑

## 4. into_iter() vs iter()

### 4.1 核心区别

| 特性 | `into_iter()` | `iter()` |
|------|--------------|----------|
| 所有权 | 消耗 `self` | 借用 `&self` |
| 返回类型 | `T`（拥有值） | `&T`（引用） |
| 使用后 | 原集合不可用 | 原集合仍可用 |

### 4.2 使用场景

**into_iter()** - 当你需要元素的所有权时：

```rust
let numbers = vec![1, 2, 3];
for n in numbers.into_iter() {  // n 的类型是 i32
    println!("{}", n);
}
// numbers 已被消耗
```

**iter()** - 当你只需要查看元素时：

```rust
let numbers = vec![1, 2, 3];
for n in numbers.iter() {  // n 的类型是 &i32
    println!("{}", n);
}
// numbers 仍然可用
```

### 4.3 练习 05：实现 iter() 方法

**目标**：提供一个不消耗所有权的迭代方式

**实现**：

```rust
// exercises/06_ticket_management/05_iter/src/lib.rs

impl TicketStore {
    pub fn iter(&self) -> std::slice::Iter<'_, Ticket> {
        self.tickets.iter()
    }
}
```

**使用方式**：

```rust
let store = TicketStore::new();
// ... 添加票据 ...

// 不消耗所有权，获取 &Ticket
for ticket in store.iter() {
    // ticket 的类型是 &Ticket（引用）
    println!("{}", ticket.title);
}

// store 仍然可以继续使用
```

**关键点**：
- `Vec::iter()` 返回 `std::slice::Iter<'_, T>`
- `'_` 是生命周期占位符，表示"与 `&self` 引用一样长"
- 返回的是引用，不会消耗 `Vec` 的所有权

## 5. 生命周期与迭代器

### 5.1 为什么需要生命周期？

当为**引用类型**实现 `IntoIterator` 时，必须显式指定生命周期：

```rust
// ❌ 错误：无法使用 `'_`
impl IntoIterator for &TicketStore {
    type Item = &Ticket;
    type IntoIter = std::slice::Iter<'_, Ticket>;  // 编译错误！
    // ...
}
```

**原因**：在关联类型中，`'_` 不能用于指代 `self` 的生命周期。

### 5.2 生命周期参数的作用

生命周期是编译器用来跟踪引用有效期的**标签**：

```rust
impl<'a> IntoIterator for &'a TicketStore {
    type Item = &'a Ticket;                     // 引用的有效期
    type IntoIter = std::slice::Iter<'a, Ticket>;

    fn into_iter(self) -> Self::IntoIter {
        self.iter()
    }
}
```

**含义**：
- `'a` 将 `&TicketStore` 引用的生命周期与迭代器关联起来
- 保证迭代器不会比它引用的 `TicketStore` 活得更久
- 避免悬垂指针（dangling pointers）和使用后释放（use-after-free）的 bug

### 5.3 生命周期省略规则

在函数签名中，Rust 允许省略显式生命周期注解：

```rust
// 完整写法
pub fn iter<'a>(&'a self) -> std::slice::Iter<'a, Ticket> {
    self.tickets.iter()
}

// 省略写法（编译器自动推断）
pub fn iter(&self) -> std::slice::Iter<'_, Ticket> {
    self.tickets.iter()
}
```

### 5.4 练习 06：为引用实现 IntoIterator

**实现**：

```rust
// exercises/06_ticket_management/06_lifetimes/src/lib.rs

impl<'a> IntoIterator for &'a TicketStore {
    type Item = &'a Ticket;
    type IntoIter = std::slice::Iter<'a, Ticket>;

    fn into_iter(self) -> Self::IntoIter {
        self.iter()
    }
}
```

**使用方式**：

```rust
let store = TicketStore::new();
// ... 添加票据 ...

// 使用引用进行迭代
for ticket in &store {
    // ticket 的类型是 &Ticket
    println!("{}", ticket.title);
}

// store 仍然可用
```

**测试验证**：

```rust
let tickets: Vec<&Ticket> = store.iter().collect();
let tickets2: Vec<&Ticket> = (&store).into_iter().collect();
assert_eq!(tickets, tickets2);  // 两者结果相同
```

## 6. 组合子（Combinators）

### 6.1 什么是组合子？

组合子是 `Iterator` trait 提供的方法，用于**转换、过滤和组合**迭代器。

### 6.2 常用组合子

| 组合子 | 功能 | 示例 |
|--------|------|------|
| `map` | 对每个元素应用函数 | `.map(\|x\| x * 2)` |
| `filter` | 保留满足条件的元素 | `.filter(\|&x\| x > 5)` |
| `filter_map` | 同时过滤和转换 | `.filter_map(\|x\| x.ok())` |
| `cloned` | 将引用迭代器转换为值迭代器 | `.cloned()` |
| `enumerate` | 添加索引 | `.enumerate()` → `(0, &v1), (1, &v2)...` |
| `skip` | 跳过前 n 个元素 | `.skip(3)` |
| `take` | 只取前 n 个元素 | `.take(5)` |
| `chain` | 连接两个迭代器 | `.iter().chain(other.iter())` |
| `sum` | 求和 | `.sum()` |
| `collect` | 收集到集合 | `.collect::<Vec<_>>()` |

### 6.3 链式调用

组合子的强大之处在于可以链式调用：

```rust
let numbers = vec![1, 2, 3, 4, 5];

// 计算偶数的平方和
let sum: u32 = numbers.iter()
    .filter(|&n| n % 2 == 0)    // 过滤：[2, 4]
    .map(|&n| n * n)            // 转换：[4, 16]
    .sum();                     // 求和：20

println!("{}", sum); // 20
```

## 7. 闭包（Closures）

### 7.1 什么是闭包？

闭包是**匿名函数**，使用 `|args| body` 语法定义：

```rust
// 单行表达式
let add_one = |x| x + 1;

// 代码块
let add_one = |x| {
    let result = x + 1;
    result
};
```

### 7.2 闭包特性

#### 1) 捕获环境变量

```rust
let factor = 10;
let multiply = |x| x * factor;  // 捕获外部的 factor
println!("{}", multiply(5)); // 50
```

#### 2) 多参数

```rust
let add = |x, y| x + y;
println!("{}", add(1, 2)); // 3
```

#### 3) 类型注解（可选）

```rust
// 仅注解参数类型
let add_one = |x: i32| x + 1;

// 注解参数和返回类型
let add_one: fn(i32) -> i32 = |x| x + 1;
```

### 7.3 闭包与组合子

组合子接受闭包作为参数，定义"如何"转换或过滤元素：

```rust
// filter 的闭包：|&Ticket| -> bool
.filter(|ticket| {
    ticket.status == Status::ToDo  // 返回 true 则保留
})

// map 的闭包：|&u32| -> u32
.map(|&n| n * n)  // 将每个元素平方
```

### 7.4 闭包参数类型

在组合子中，闭包参数通常是**引用**：

```rust
numbers.iter()
    .filter(|&n| n % 2 == 0)  // |&n| 解引用 &u32 得到 u32
    .map(|&n| n * n)          // |&n| 解引用 &u32 得到 u32
```

## 8. collect 方法

### 8.1 作用

`collect()` 消耗迭代器，将元素收集到一个集合中：

```rust
let numbers = vec![1, 2, 3, 4, 5];

let squares_of_evens: Vec<u32> = numbers.iter()
    .filter(|&n| n % 2 == 0)
    .map(|&n| n * n)
    .collect();  // 收集到 Vec<u32>
```

### 8.2 类型推断

`collect` 是泛型的，需要类型提示才能推断目标类型：

#### 方法 1：注解变量类型

```rust
let result: Vec<&Ticket> = store.to_dos();
```

#### 方法 2：Turbofish 语法

```rust
let result = store.to_dos().collect::<Vec<&Ticket>>();
//                       ^^^^^^^^^^^^^^^^^^^^^^^^
//                       像鱼的形状，因此叫 turbofish
```

### 8.3 可收集到的类型

只要有足够的类型信息，`collect` 可以收集到多种类型：

```rust
// Vec
let v: Vec<_> = iter.collect();

// HashMap
let map: HashMap<_, _> = iter.collect();

// HashSet
let set: HashSet<_> = iter.collect();
```

## 9. 实践示例

### 9.1 练习 07：使用组合子和闭包

**目标**：实现 `to_dos()` 方法，返回所有状态为 `ToDo` 的票据引用

**实现**：

```rust
// exercises/06_ticket_management/07_combinators/src/lib.rs

impl TicketStore {
    /// 返回所有状态为 `ToDo` 的票据的引用
    pub fn to_dos(&self) -> Vec<&Ticket> {
        self.tickets
            .iter()                      // 1. 创建迭代器，遍历 &Ticket
            .filter(|ticket| {           // 2. 组合子：过滤元素
                ticket.status == Status::ToDo  // 3. 闭包逻辑：判断状态
            })
            .collect()                    // 4. 收集到 Vec<&Ticket>
    }
}
```

**数据流**：

```
Vec<Ticket> (self.tickets)
    ↓ iter()
Iter<&Ticket>
    ↓ filter(|ticket| ticket.status == Status::ToDo)
Iter<&Ticket> (仅包含 ToDo 状态的)
    ↓ collect()
Vec<&Ticket> (结果)
```

**测试验证**：

```rust
#[test]
fn todos() {
    let mut store = TicketStore::new();

    let todo = Ticket {
        title: ticket_title(),
        description: ticket_description(),
        status: Status::ToDo,
    };
    store.add_ticket(todo.clone());

    let in_progress = Ticket {
        title: ticket_title(),
        description: ticket_description(),
        status: Status::InProgress,
    };
    store.add_ticket(in_progress);

    let todos: Vec<&Ticket> = store.to_dos();
    assert_eq!(todos.len(), 1);
    assert_eq!(todos[0], &todo);  // 只返回了 todo 票据
}
```

### 9.2 完整示例：组合多种操作

假设我们需要实现一个功能：获取所有高优先级（描述中包含"urgent"）的待办事项标题：

```rust
impl TicketStore {
    pub fn urgent_todos(&self) -> Vec<String> {
        self.tickets
            .iter()                              // 遍历所有票据
            .filter(|ticket| {                   // 过滤：只保留 ToDo
                ticket.status == Status::ToDo
            })
            .filter(|ticket| {                   // 过滤：只保留紧急的
                ticket.description
                    .to_lowercase()
                    .contains("urgent")
            })
            .map(|ticket| {                      // 转换：提取标题
                ticket.title.to_string()
            })
            .collect()                           // 收集到 Vec<String>
    }
}
```

## 10. 最佳实践

### 10.1 优先使用迭代器而非索引

```rust
// ✅ 推荐：使用迭代器
for ticket in &store {
    println!("{}", ticket.title);
}

// ❌ 避免：使用索引
for i in 0..store.len() {
    println!("{}", store[i].title);
}
```

### 10.2 根据需求选择迭代方式

| 需求 | 方法 |
|------|------|
| 需要元素所有权 | `into_iter()` 或 `for x in collection` |
| 只需查看元素 | `iter()` 或 `for x in &collection` |
| 修改元素 | `iter_mut()` 或 `for x in &mut collection` |

### 10.3 组合子的链式调用

将多个操作链式调用，而非多次循环：

```rust
// ✅ 推荐：一次遍历完成所有操作
let result: Vec<_> = items.iter()
    .filter(|&x| x > 0)
    .map(|&x| x * 2)
    .collect();

// ❌ 避免：多次遍历
let filtered: Vec<_> = items.iter()
    .filter(|&x| x > 0)
    .collect();
let result: Vec<_> = filtered.iter()
    .map(|&x| x * 2)
    .collect();
```

### 10.4 同时提供 iter() 和 IntoIterator

为自定义类型提供两种迭代方式：

```rust
impl TicketStore {
    // 显式的迭代方法
    pub fn iter(&self) -> std::slice::Iter<'_, Ticket> {
        self.tickets.iter()
    }
}

// 用于 for 循环（隐式）
impl IntoIterator for TicketStore {
    // ... 消耗所有权
}

impl<'a> IntoIterator for &'a TicketStore {
    // ... 借用
}
```

## 11. 总结

### 11.1 核心概念关系

```
for 循环
    ↓ 解语法糖
IntoIterator::into_iter()
    ↓ 返回
Iterator (next() 方法)
    ↓ 使用
组合子 (map, filter, etc.)
    ↓ 接受
闭包 (|args| body)
    ↓ 最终
collect() 或 for 循环
```

### 11.2 关键要点

1. **`for` 循环**基于 `IntoIterator` 和 `Iterator` trait 实现
2. **`into_iter()`** 消耗所有权，返回 `T`
3. **`iter()`** 借用，返回 `&T`
4. **生命周期**确保引用的有效性
5. **组合子**提供强大的转换和过滤能力
6. **闭包**为组合子提供自定义逻辑
7. **`collect()`** 将迭代器结果收集到集合
